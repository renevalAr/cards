```python
from sqlalchemy import create_engine, pool
from app.config import get_settings

def run_migrations_online():
    settings = get_settings()
    url = settings.DATABASE_URL.replace("postgresql+asyncpg://", "postgresql://")
    connectable = create_engine(url, poolclass=pool.NullPool)
    with connectable.connect() as connection:
        context.configure(connection=connection, target_metadata=target_metadata)
        with context.begin_transaction():
            context.run_migrations()
```
**Критерий:** `alembic upgrade head` выполняется без ошибок

### 1.5 Исправить `decode_token`
**Файл:** `backend/app/services/auth.py:31-32`
**Проблема:** Не ловит `ExpiredSignatureError`
**Решение:**
```python
from jose import jwt, JWTError, ExpiredSignatureError

def decode_token(token: str) -> dict:
    try:
        return jwt.decode(token, settings.SECRET_KEY, algorithms=["HS256"])
    except ExpiredSignatureError:
        raise ValueError("Token expired")
    except JWTError:
        raise ValueError("Invalid token")
```
**Критерий:** Истёкший токен возвращает 401, не 500

### 1.6 Исправить `deck_to_response` (N+1)
**Файл:** `backend/app/routers/decks.py:13-24`
**Проблема:** `len(deck.cards)` загружает все карты
**Решение:**
```python
from sqlalchemy import func, select

@router.get("/{deck_id}", response_model=DeckResponse)
def get_deck(deck_id: UUID, user: User = Depends(get_current_user), db=Depends(get_db)):
    deck = db.get(Deck, deck_id)
    if not deck or deck.owner_id != user.id:
        raise HTTPException(status_code=404)
    count = db.execute(select(func.count(Card.id)).where(Card.deck_id == deck_id)).scalar()
    return deck_to_response(deck, cards_count=count)
```
**Критерий:** Запрос карточки делает ровно 2 SQL запроса, не N+1

## Фаза 2: Frontend интеграция

### 2.1 Добавить hash-based роутинг
**Файл:** `frontend/js/router.js` (новый)
**Проблема:** Нет навигации между страницами
**Решение:**
```javascript
const Router = {
  currentRoute: null,
  
  init() {
    window.addEventListener("hashchange", () => this._handleRoute());
    this._handleRoute();
  },
  
  _handleRoute() {
    const hash = window.location.hash || "#menu";
    const [route, ...params] = hash.split("/");
    
    switch(route) {
      case "#login": showAuthModal(); break;
      case "#register": showAuthModal(); break;
      case "#deck": DeckUI.show(params[0]); break;
      case "#d": Share.viewPublicDeck(params[0]); break;
      case "#menu": openMenu(); break;
      default: openMenu();
    }
  },
  
  navigate(path) {
    window.location.hash = path;
  }
};
```
**Критерий:** `#deck/123` открывает колоду, `#d/abc` открывает публичную колоду

### 2.3 Синхронизировать state с API

**Проблема:** `state` не синхронизируется с сервером
**Решение:**
```javascript
const AppData = {
  async syncFromServer() {
    try {
      const decks = await Decks.list();
      state.decks = decks.map(d => ({ id: d.id, name: d.name, twoSided: d.two_sided }));
      state.cards = [];
      for (const deck of decks) {
        const cards = await Decks.getCards(deck.id);
        state.cards.push(...cards.items.map(c => ({ ...c, deckId: deck.id })));
      }
      saveState();
      render();
    } catch (err) {
      console.error("Sync failed:", err);
      showToast("Не удалось загрузить данные с сервера", "warn");
    }
  }
};
```
**Критерий:** Данные с сервера отображаются в UI

### 2.8 Добавить CSRF защиту
**Файл:** `frontend/js/api.js`
**Проблема:** Нет CSRF токена
**Решение:**
```javascript
async request(method, path, body = null, retry = true) {
  const options = {
    method,
    headers: {},
    credentials: "include",
  };
  
  if (body) {
    options.headers["Content-Type"] = "application/json";
    options.headers["X-CSRF-Token"] = this._getCsrfToken();
    options.body = JSON.stringify(body);
  }
  // ...
}

_getCsrfToken() {
  return document.cookie.match(/csrf_token=([^;]+)/)?.[1] || "";
}
```
**Критерий:** CSRF токен отправляется с каждым mutating запросом

**Файл:** `backend/app/schemas/__init__.py`
**Проблема:** Пароль может быть слабым
**Решение:**
```python
from pydantic import field_validator

class UserCreate(BaseModel):
    password: str = Field(..., min_length=8, max_length=72)
    
    @field_validator("password")
    @classmethod
    def validate_password(cls, v):
        if not any(c.isupper() for c in v):
            raise ValueError("Password must contain uppercase letter")
        if not any(c.isdigit() for c in v):
            raise ValueError("Password must contain digit")
        return v
```
